# 資産分散チャート

保有資産を円グラフで見える化し、目標配分との差やリバランス額を計算する、ブラウザだけで動く無料ツールです。

**使う**: このリポジトリの GitHub Pages の URL を開いてください。

## データの扱い
- 入力した資産データは、**開いた人のブラウザの中にだけ**保存されます。このサイトやGitHubに送られることはありません。
- 通信するのは、為替レートと暗号資産・金の価格を取得するときだけです（取得先: `api.frankfurter.dev` / `latest.currency-api.pages.dev`。送るのは通貨・銘柄の種類だけ）。それ以外の通信は、Content-Security-Policy で遮断しています。
- パスコード保護（AES-256-GCM）、リカバリーキー、パスキー（WebAuthn PRF）に対応しています。

## 改ざんの確認
`index.html` の SHA-256 ハッシュ値は、配布元が別の経路（講義資料など）で公開している値と一致する必要があります。

```
certutil -hashfile index.html SHA256      (Windows)
shasum -a 256 index.html                  (Mac)
```

このツールは投資助言を行うものではありません。教育・個人利用を目的としています。
